Código original do projeto publicado sob MIT. Não inclui jogos comerciais, ROMs, ISOs, WADs, NAND, chaves, firmware ou dados proprietários.

## Validação da primeira entrega

1. Verificar os arquivos de diagnóstico, testes e workflow na branch main.
2. Conferir os jobs static-tests e homebrew-build em GitHub Actions.
3. Em caso de CI verde, baixar o artifact de diagnóstico; só o teste em Dolphin GC ou hardware pode confirmar execução.
4. Não divulgar como compatibilidade Wii no GameCube: o código GC ainda não executa binários Wii.
